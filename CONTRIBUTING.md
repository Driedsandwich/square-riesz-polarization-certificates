# Contributing

Contributions that improve reproducibility, identify certificate bugs, provide independent verifier implementations, or clarify claim boundaries are welcome.

- Do not describe a fixed-configuration lower bound as a proof of global optimality.
- Include a minimal reproducible example for any reported certificate failure.
- Keep numerical candidate-generation code separate from exact certificate claims.
- Do not add third-party images, private correspondence, credentials, or personal data.
- Run `python scripts/verify_manifest.py` and the relevant certifiers before proposing changes.
