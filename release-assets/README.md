# Release assets

The GitHub `v1.0.0` Release contains exactly two manually uploaded canonical assets:

- `square-riesz-polarization-certificates-v1.0.0.zip`
- `square-riesz-polarization-certificates-v1.0.0.zip.sha256`

The canonical ZIP is generated outside the repository to avoid recursive packaging.

```text
size: 610,729 bytes
SHA-256: 3efed92c6227594f04374b6b3d795c1c8f5d0fc6942734678559e93c9220351b
```

GitHub's automatically generated “Source code” archives are convenience downloads and are not the canonical deterministic ZIP.
