# Background and references

These references provide terminology and background. Their inclusion does not establish novelty for the configurations in this repository.

1. Erich Friedman, “Maximizing Minimum Light Intensity,” record board: https://erich-friedman.github.io/packing/light/
2. Tamás Erdélyi and Edward B. Saff, “Riesz Polarization Inequalities in Higher Dimensions,” *Journal of Approximation Theory* 171 (2013), 128–147; arXiv:1206.4729, https://arxiv.org/abs/1206.4729

The problem is a Riesz \(s=2\) polarization, or Chebyshev-type max-min potential, problem on the unit square. This repository does not claim an exhaustive literature search or comprehensive novelty determination.
