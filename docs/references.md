# Background and references

These references provide the primary problem source and mathematical background. Their inclusion does not establish novelty for the configurations in this repository.

## Primary source

Erich Friedman, “Maximizing Minimum Light Intensity,” *Erich's Packing Center*, https://erich-friedman.github.io/packing/light/

Friedman's page defines the unit-square minimum-light-intensity problem and maintains the associated numerical record board.

## Background literature

Tamás Erdélyi and Edward B. Saff, “Riesz Polarization Inequalities in Higher Dimensions,” *Journal of Approximation Theory* 171 (2013), 128–147; arXiv:1206.4729, https://arxiv.org/abs/1206.4729

The problem is a Riesz \(s=2\) polarization, or Chebyshev-type max-min potential, problem on the unit square. This repository does not claim an exhaustive literature search or comprehensive novelty determination.
